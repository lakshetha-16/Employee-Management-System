# Employee Management System

A Flask-based Employee Management System developed using Python, Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- Dashboard
- Employee Management (CRUD)
- Department Management
- Reports Dashboard
- Settings Page
- Search Employees
- Responsive UI
- SQLite Database

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Font Awesome

## How to Run

```bash
pip install flask
python app.py
```

Open:

```
http://127.0.0.1:5000
```
